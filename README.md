## 🚀 Featured Projects

### 🛰️ AI-Driven GNSS Positioning for Vehicle Navigation
*Research project during my internship at RESOLVE South (SUPARCO)*

Improving GNSS positioning accuracy for moving vehicles using machine learning.

- Merged multi-source GNSS data (**SPP, L5, B2B, NRTK**) from three vehicle speeds (10, 20, 30 km/h) into a timestamp-aligned dataset of **1,669 records**, with NRTK as the reference
- Trained **XGBoost** models for B2B correction: about **94% lower horizontal error** and **96% lower vertical error** on held-out test data
- Built an **LSTM + Adaptive Kalman Filter** pipeline to reconstruct the vehicle path during simulated 60-second GNSS outages

`Python` `Pandas` `NumPy` `XGBoost` `LSTM` `Kalman Filter`

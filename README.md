## Projects

**[AI-Driven GNSS Positioning](https://github.com/humairarajar)** (internship research project)
Used XGBoost to correct vehicle GNSS positioning errors, reducing horizontal error by about 94% and vertical error by about 96% on test data. Also built an LSTM + Adaptive Kalman Filter model to reconstruct the vehicle path during 60-second signal outages.

**[Credit Risk Prediction](https://github.com/humairarajar/credit-risk-mlops)**
End-to-end ML pipeline to predict loan default on 150,000+ records. Compared Logistic Regression, Random Forest, and XGBoost, tracked with MLflow, and deployed with FastAPI.

**[AI Code Reviewer](https://github.com/humairarajar/AiCodeReviewer)**
Flask app that combines static code analysis (Radon) with LLM-based code reviews for Python, JavaScript, Java, and C++.

**[Smart Document Insights](https://github.com/humairarajar/docInsights)**
RAG system to chat with PDFs using Sentence Transformers, FAISS, and Streamlit.

**[CSV Chat](https://github.com/humairarajar/CSV-into-Ai-chatbot)**
Upload a CSV and ask questions in plain English, with automatic charts. Built in 14 days.

**[RAG ChatBot](https://github.com/humairarajar/RagChatBot)**
Document-based question answering using retrieval and language models.
